# GROMACS Console 0.2.7

0.2.7 改善首次使用、任务监控、协议复用与结果交付，并加强任务文件和运行进程保护。Windows x64 安装器和便携 ZIP 包含本版本源码、内置帮助与离线教学结果，均附 SHA-256 校验文件。

## 使用体验

- 引导与专业视图共享参数，新增流程选择、输入映射、环境就绪提示与提交前的协议摘要。
- 首次使用可浏览离线结果；运行教学示例可用单 CPU 线程完成 64 个氩原子的 1 ps 流程。示例不代表蛋白或配体研究协议。
- 运行详情从 GROMACS 原生日志补充进度、模拟时间与更新时间；信息不足时明确显示无法估算。
- 按项目、标签和备注整理与搜索任务，支持置顶；协议模板可保存版本、导入和导出。
- 结果摘要包包含可离线打开的报告、协议与已有图表；摘要说明质量检查、被排除文件和使用边界。
- 新增内置帮助、可预览的脱敏诊断和本机任务统计。统计不上传，也不等同于安装转化率或用户留存。

## 交付与维护

- 新增空间管理，支持预览清理内容、保护输入和关键轨迹、确认后清理或删除旧任务；运行中的任务和已登记活跃进程受到保护。
- 改进大 XVG 文件读取、分析时间窗口与旧任务来源追踪，减少重复扫描和无效图表更新。
- 加强跨来源请求、参数校验、输入哈希和文件操作并发保护；结构化错误提供对应恢复建议。
- Windows 应用载荷包含快速上手、帮助文档和离线示例，并支持旧安装目录的文档升级与失败回滚。
- 修复 Windows PowerShell 5.1 向 WSL 传入脚本时可能附加 UTF-8 BOM 的兼容性问题，保留原始 LF 换行并恢复调用方编码。
- Windows 打包明确使用 UTF-8 读取中文页面和文档，并固定 WSL 脚本的 LF 换行；编译器采用固定版本和 SHA-256 校验。
- 前端 JS、CSS 和入口模板采用统一内容指纹，CI 检查缓存版本是否同步。
- 标签构建准备 Draft Release，附 EXE、ZIP、SHA-256 和签名状态。正式发布仍由维护者审核。
- 可选 Windows 代码签名使用维护者提供的证书；未配置时明确标注 unsigned，不声称已验证发布者身份。

## 下载与更新

从本 Release 下载 `GromacsConsole-0.2.7-windows-x64-setup.exe`，或解压 `GromacsConsole-0.2.7-windows-x64.zip` 后运行 `Start.cmd`。首次配置需要联网和兼容的 Windows 10/11 x64 + WSL2。现有用户安装到原 Windows 目录，再运行 **Configure or Update**；已有设置和模拟结果保留。

## 升级与验证边界

先等待运行任务结束，再执行 Configure or Update；不要通过停止工作进程强行升级正在计算的环境。已打开网页在服务更新完成后重新加载。

自动化测试、真实短模拟、Windows runner 测试与 Windows 实机验收应分别记录。完整 WSL2 首次配置、UAC/重启恢复和 GPU 硬件仍按[发布清单](RELEASE-CHECKLIST.md)验收；没有证据的项目保持“未验证”。
