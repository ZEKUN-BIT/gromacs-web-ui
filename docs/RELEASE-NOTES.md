# GROMACS Console 0.2.9

0.2.9 将 AI 对话、模型配置管理和近期分析优化加入 Windows 安装包。此前仅推送源码不会更新已发布的 EXE；本版本使用新的版本标签生成完整安装器和便携 ZIP。

## 更新内容

- 首页直接与 OpenAI 或 DeepSeek 对话，配置一次 API Key 后自动沿用；“模型与 API”可查看保存状态、获取模型列表并切换 DeepSeek 系列。
- AI 支持查询任务、生成模拟草案，以及经逐项确认的复制、取消、续跑、重试和分析操作。密钥由本机服务保存，不返回浏览器；对话和任务摘要会发送给所选服务商，详见 [AI 调度指南](AI-AGENT.md)。
- 改善对话消息排版、代码复制、历史恢复、输入法、手机布局和网络错误提示。
- 已有轨迹分析增加规模与磁盘预检、复制进度和准备取消；限制分析并发，完善执行服务健康状态、失败恢复、任务记录草稿及绘图导出。
- 修复旧清理预览被拒绝时仍递增存储修订、覆盖成功清理状态的问题；同一旧预览不会重复清理。
- Windows 包包含 AI 模块、前端资源和帮助文档，保留中文安装向导、版本与实例核验、旧任务保护及既有 WSL 环境复用。
- Linux 源码安装增加桌面和应用菜单启动器，可后台启动并自动打开浏览器。

## 下载与更新

下载 `GromacsConsole-0.2.9-windows-x64-setup.exe` 安装到原目录，或完整解压 `GromacsConsole-0.2.9-windows-x64.zip` 后运行 `Start.cmd`。两种产物均附 SHA-256 校验文件。

已有计算任务时，请等待任务结束，再执行 **Configure or Update**。更新沿用既有 WSL 环境、设置和模拟结果。之后从 **GROMACS Console** 快捷方式启动，确认启动窗口显示 `GROMACS Console 0.2.9`。AI 密钥和对话按本机运行目录保存，不随安装包分发。

## 验证边界

构建、PowerShell 双宿主回归、实际 EXE 中文向导检查和 Python 3.11/3.12 应用测试以本 Release 对应的 GitHub Actions 记录为准。安装包包含文件、版本及 SHA-256 另作回读核验。

签名状态由附件 `windows-signing.json` 记录；未配置发行者证书时为 **unsigned**。CI 中文欢迎页检查没有执行 WSL 首次配置，完整 Windows/WSL 安装、UAC/重启恢复和 GPU 硬件验收仍按[发布清单](RELEASE-CHECKLIST.md)记录。
