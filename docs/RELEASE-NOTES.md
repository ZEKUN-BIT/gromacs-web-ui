# GROMACS Console 0.2.10

0.2.10 完善科研工作台的视觉、提交反馈、长任务监控和恢复能力，并将这些更新纳入 Windows 安装包。

## 更新内容

- 统一浅色科研工作台的字体、字号、间距、颜色与组件状态，保留深色主题、系统中文字体和手机布局。增加可访问性、截图及资源预算检查。
- 参数错误定位到字段；命令和协议预览通过后才提交确认的参数与文件，防止异步预览过期或重复提交。连接状态显示上次同步时间，断线可重试。
- 初始化失败可直接重试；另一标签页修改草稿时提示选择版本，保留本页参数；任务、工作区、详情页签和历史筛选支持地址栏及浏览器后退恢复。
- 输出文件支持服务端搜索与分页，可查找原先 1000 项上限之外的文件；保留展开状态。研究报告缓存、表格搜索排序分页和请求取消减少重复读取。
- AI 设置延迟到打开工作区后加载；配置读取失败时仍能安全打开设置。会话条件请求跳过未变化的响应，后台操作提供进度、取消及结果核实。
- 优化任务数据库快照、存储扫描、准备中断恢复和进程清理；执行清单记录输入、运行身份与源码指纹，便于复现和追踪。
- 增加真实浏览器上传 TPR、预览确认、worker/GROMACS、SSE、日志和下载回归，以及 Linux/Windows 的 Chromium、Firefox 原生字体与响应布局检查。
- filelock 升至 4.2.1，重新生成并检查运行、开发和 Windows 科学工具依赖锁。

## 下载与更新

安装 `GromacsConsole-0.2.10-windows-x64-setup.exe`，或完整解压 `GromacsConsole-0.2.10-windows-x64.zip` 后运行 `Start.cmd`。两种产物均附 SHA-256。

请在已有计算任务结束后执行 **Configure or Update**。更新沿用既有 WSL 环境、设置和模拟结果；启动窗口应显示 `GROMACS Console 0.2.10`。密钥、对话、输入文件和本地运行目录不随安装包分发。

## 验证边界

验证记录以本标签的 GitHub Actions 为准；测试覆盖真实 CPU GROMACS 及隔离浏览器，合成 API 用于故障、竞争和视觉回归。半宽视口与缩小可视高度属于缩放和手机键盘布局压力模拟，不代表物理设备或操作系统缩放验收。

`windows-signing.json` 记录 EXE 签名状态；未配置发行者证书时为 **unsigned**。Windows CI 检查 PowerShell 双宿主、实际中文安装欢迎页和原生浏览器布局；完整 Windows/WSL 首次安装、UAC/重启与 GPU 硬件验收仍见 [发布清单](RELEASE-CHECKLIST.md)。
