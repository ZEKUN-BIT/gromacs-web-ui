# AI 调度助手

AI 调度助手接入 OpenAI 或 DeepSeek 的模型，用自然语言查询任务、准备模拟方案，以及提出运行和分析操作。模型通过项目提供的工具工作；修改任务前会显示目标、参数和影响，由你点击“确认执行”。

## 配置与开始使用

1. 首页即为 AI 对话区。首次使用点击“配置模型”或右上角“模型与 API”，选择服务商和模型，输入对应的 API Key，点击“保存设置”。设置窗口自动关闭，之后刷新页面或重启同一本机服务都会自动沿用配置。
2. 如需验证密钥、模型权限和工具调用能力，可在“模型与 API”中点击“保存并测试连接”。它先保存当前输入，再测试当前服务商与模型，结果显示在设置窗口中。单独“保存设置”不调用模型；连接测试会调用服务商 API，可能产生费用。
3. 直接在首页输入研究目标并点击“发送”，或选择快捷问题填入输入框。无需打开聊天窗口，也无需重新填写 API Key。需要引用当前任务时，勾选“附带当前任务”；默认不附带。
4. 核对助手生成的方案，再逐项确认或拒绝。自然语言中的“批准”不会执行待确认操作。

需要服务商提供的 API 账户和可用额度。费用由服务商按 API 使用情况收取；请单独确认自己的 API 权限和计费状态。

| 服务商 | 默认模型（可修改） | 固定请求地址 |
| --- | --- | --- |
| OpenAI | `gpt-6.1-sol` | `https://api.openai.com/v1/responses` |
| DeepSeek | `deepseek-flash` | `https://api.deepseek.com/chat/completions` |

模型名称必须对应账户可用且支持工具调用的模型。此版本使用官方 HTTPS 地址，不支持自定义 Base URL；第三方中转商的密钥不能直接用于官方接口。

联网时读取启动服务的 `HTTPS_PROXY`（或小写 `https_proxy`），未设置时使用 `ALL_PROXY`，并遵循 `NO_PROXY`。代理地址须为 `http://`，通过 HTTP CONNECT 建立隧道后仍验证官方服务的 TLS 证书；不支持直接填写 SOCKS 或 HTTPS 代理地址。只设置 `HTTP_PROXY` 不会代理本功能的 HTTPS 请求。修改环境变量后需要重新启动服务。

每个服务商分别保存模型和密钥。切换服务商并保存后，新建对话以使用该服务商；已有对话保留原来的服务商。同一服务商内更换模型后，下一轮请求使用新配置，界面会区分上次和下次使用的模型。已保存密钥时显示“设置已保存 · 自动沿用”，使用环境密钥时显示“已读取环境配置 · 自动沿用”；这些状态不代表已验证联网。密钥输入框不会回显已保存值，留空表示保留现有密钥，不代表配置丢失。“移除已保存密钥”只删除本机配置中的密钥。

也可以在启动 Web 服务前设置服务端环境变量 `OPENAI_API_KEY` 或 `DEEPSEEK_API_KEY`。已保存的密钥优先；删除后会回退到环境变量。要完全停用相应凭据，还需移除启动环境中的变量并重新启动服务。

### 查看已保存配置与切换模型

打开“模型与 API”，顶部的“已保存的连接”展示各服务商的模型、密钥来源和服务地址，并标明当前连接。点击卡片的“查看 / 修改”可编辑该服务商；密钥仅显示保存状态，留空会继续沿用。

DeepSeek 模型下拉框内置 `deepseek-flash` 和 `deepseek-v4-pro`。选择另一模型并点击“保存设置”，同一 DeepSeek 对话的下一轮即使用新模型；无需重新填写密钥，也无需新建对话。原有回复保留原模型信息。切换服务商仍需要新建对话。

“获取可用模型”使用正在编辑的服务商已保存的密钥，读取官方模型列表，不改变当前连接或选定模型，也不发送对话或生成回复。模型列表仅在点击时获取；新填写的密钥需要先保存。读取失败时可继续使用内置模型，或选择“自定义模型 ID…”。服务商返回的模型可能不支持本项目需要的工具调用，可用“保存并测试连接”验证。

## 可执行的工作

| 能力 | 行为 |
| --- | --- |
| 查看工作区、搜索任务、查看任务详情 | 读取任务摘要、资源设置、执行器状态和质量检查状态。 |
| 查看分析输入、查看工作流 | 列出任务内可用分析文件的相对名称与大小，以及工作流和协议模板摘要。 |
| 复制、取消、恢复、重试任务 | 生成待确认方案；确认后调用原有任务生命周期接口。恢复需要可用 checkpoint，重试不会跳过科学检查。 |
| 创建分析任务 | 预检选定输入，确认后复制输入并加入分析队列。 |
| 准备新模拟 | 生成参数草案；确认后可应用到原有表单，你仍需上传文件、核对科学参数并手动提交。 |

共提供 5 个只读工具和 6 个需确认的操作工具。自定义命令、可执行程序覆盖、跳过检查等任务需要在原任务页面处理。任务运行完成仍需检查采样质量和科学结论；配体化学信息等专业判断由研究者确认。

## 数据与密钥

发送消息后，对话和工具读取的数据会传给所选服务商。工具数据包括任务名称、项目、标签、状态、科学参数、资源信息、质量检查状态、协议摘要，以及分析文件的相对名称和大小。工具不会上传结构文件、轨迹、原始运行日志或任意本机文件。请在发送前确认消息和任务摘要适合交给该服务商处理。

API Key 由本机 Web 服务保存和使用，不返回给页面，也不写入浏览器存储。默认配置位于 `runtime/agent/providers.json`；实际路径随项目运行目录配置变化。在 Linux/WSL 中，`agent` 目录权限为 `0700`，配置文件权限为 `0600`。文件使用受权限保护的明文存储，不是加密保险库；保护运行目录及其备份。显示和持久化对话前会隐藏已配置密钥，仍应把密钥只填在密钥输入框中。

OpenAI 请求设置 `store: false`，并携带加密推理上下文以支持连续工具调用；这不替代服务商自身的数据处理政策。DeepSeek 工具调用按接口要求延续推理上下文。内部工具历史和推理上下文不会返回给页面。

AI 接口仅接受本机回环连接，并检查浏览器同源请求。这是面向可信本机用户的功能，没有账户登录和多用户权限隔离，不支持通过局域网公开使用。

## 对话、确认与恢复

对话及操作记录保存在本机运行目录的 `agent/conversations.sqlite3` 中。可从历史对话切换继续处理；“清除本次对话”会删除该对话及其待确认方案，已创建或修改的任务保留。

首页对话区的消息独立滚动，输入框保持在底部。阅读上方记录时，新回复不会强行把页面拉到底部；点击“回到最新”即可继续阅读。输入框随内容增高，普通 Enter 换行，Ctrl / ⌘ + Enter 发送，中文输入法选词时不会触发快捷发送。空白内容不能发送。

待确认及需要关注的操作直接显示；已完成、已拒绝和已过期的操作收进“已处理操作”。确认后会展开结果，便于应用草案或查看任务；继续发送新消息时收起记录，为回复留出空间。

助手回复支持标题、列表、引用、简单表格、行内代码和围栏代码块，可复制整条消息或单个代码块。只支持显式 HTTP(S) 链接；HTML、图片及其他链接协议按文字显示，不执行模型生成的代码。复杂嵌套 Markdown 不在支持范围内。

同一页面内，每个会话分别保留未发送的草稿，切换对话或暂时查看任务详情后返回可恢复。草稿只留在页面内存，刷新或关闭页面会丢弃；浏览器存储仍只保存当前会话 ID，不保存草稿和 API Key。

| 限制 | 数值 |
| --- | --- |
| 本机保留对话 | 最多 200 个；达到上限后先清除不需要的历史对话。 |
| 每个对话 | 最多 40 轮请求、40 个操作方案。 |
| 每轮规划 | 最多 6 次模型调用、16 次工具调用。 |
| 每轮待确认方案 | 最多 4 项。 |
| 模型调度时间预算 | 每轮 180 秒，单次网络请求最多 60 秒；本地文件准备可能更久。 |
| 并行模型请求或执行操作 | 最多 2 个。 |
| 操作预览有效期 | 30 分钟。 |

任务状态、执行步骤、任务定义或分析输入发生变化后，旧方案会被拒绝，需要重新生成并确认。重复点击和请求重发复用已记录的结果，不会重复执行同一个方案。

切换到任务详情或离开页面不等于取消正在处理的请求。网络中断时先“刷新状态”，再决定下一步。服务重启后，中断的操作会标记为结果待核实，不会自动重放；请先检查任务列表，避免重复创建任务。

### 对话前端维护

`app/static/js/agent.js` 负责会话、输入草稿、操作确认与状态同步；`agent-content.js` 单独负责安全的消息展示和复制；对话布局集中在 `app/static/agent.css`。消息和操作内容未变化时保留原 DOM 节点，避免轮询打断文字选择和展开状态。切换到任务详情或页面进入后台会暂停轮询，返回对话区后按需同步。页面初始化只读取本机配置和对话，不会自动测试连接、新建会话或发送模型请求。模型设置使用独立弹窗，普通对话始终在首页完成。

交互参考了 [assistant-ui 的 ThreadPrimitive](https://www.assistant-ui.com/docs/api-reference/primitives/thread)、[Vercel AI Chatbot 的消息列表](https://github.com/vercel/ai-chatbot/blob/main/components/chat/messages.tsx)与[输入组件](https://github.com/vercel/ai-chatbot/blob/main/components/ai-elements/prompt-input.tsx)，保留本项目原生 JavaScript 实现，未引入对应框架或依赖。

前端回归入口：`scripts/check_agent_browser.py` 覆盖四种屏幕宽度下的对话、草稿、滚动、输入法、确认与断网恢复；`scripts/check_agent_content_browser.py` 使用真实浏览器检查 Markdown 结构、XSS、外链协议、剪贴板失败和超长内容。两者拦截网络请求，不调用真实模型。

此次对话界面改动另经独立安全审查（安全敏感项：YES，十类清单均已检查，状态：PASS）：新增展示逻辑只使用 DOM 与文本节点，外链限制协议并隔离新窗口，复制仅由点击触发；不新增凭据存储、服务器权限或请求目标。依赖未改变，沿用上述已审计的锁文件。

## 本机 API

| 接口 | 用途 |
| --- | --- |
| `GET /api/agent/config` | 读取服务商、模型及密钥是否已配置；不返回密钥。 |
| `PUT /api/agent/config` | 保存 `provider`、`model` 和可选 `api_key`；`clear_api_key: true` 移除保存的密钥。 |
| `GET /api/agent/models?provider=deepseek` | 使用指定服务商已保存的密钥读取模型 ID 与显示名称；不修改配置，支持 `openai` / `deepseek`。 |
| `POST /api/agent/connection-test` | 使用已保存配置验证工具调用能力。 |
| `GET /api/agent/sessions` | 获取本机历史对话列表。 |
| `POST /api/agent/sessions` | 新建对话。 |
| `GET /api/agent/sessions/{id}` | 恢复消息及方案状态。 |
| `DELETE /api/agent/sessions/{id}` | 清除非运行中的对话；保留模拟任务。 |
| `POST /api/agent/sessions/{id}/messages` | 提交 `message`、UUID 格式的 `request_id` 和可选 `context_job_id`。 |
| `POST /api/agent/sessions/{id}/actions/{action_id}` | 用 `decision: "approve"` 或 `"reject"` 处理服务端生成的方案。 |

同一 `request_id` 只能对应同一条消息；请求结果不明时先读取对话状态。接口不接受客户端指定系统角色、工具执行结果或修改已生成方案的参数。

DeepSeek 的连接测试使用 `tool_choice: "required"` 验证工具调用，因此显式设置 `thinking: {"type": "disabled"}`。官方接口默认开启思考模式，但该模式不支持强制工具调用，组合使用会返回 HTTP 400，即使密钥有效也会失败。普通对话使用 `tool_choice: "auto"`，继续保留思考与工具调用上下文。
