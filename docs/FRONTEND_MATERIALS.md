# 工作台界面素材

本轮取法于 Ant Design 的[空状态](https://ant.design/components/empty-cn/)和[步骤条](https://ant.design/components/steps-cn/)：空白处说明发生了什么，并在确有下一步时提供操作；多步配置突出当前位置。不引入 Ant Design 组件、默认蓝色、外链字体或第三方插画。

| 素材 | 使用位置 | 使用边界 |
| --- | --- | --- |
| `simulation-cell`：模拟盒与螺旋带 | 新建任务、任务详情的结构预览 | 仅作空状态示意，不代表输入或计算结果。加载、失败和真实结构使用原有反馈与画布；不参与 PNG 导出。 |
| `run-log`：记录卡与曲线 | 无任务记录的侧栏 | 搜索无结果、项目为空及读取中分别使用搜索、文件夹、时钟图标，不展示示意曲线。 |
| 步骤序号与连接线 | 新建任务的三个配置步骤 | 根据现有 `aria-current="step"` 着色，不把跳过的步骤标记为「已完成」。 |

两幅插画均为项目原创，收录在 `app/static/illustrations/workbench.svg`。用本地 SVG `use` 引用对应符号；配色继承现有主题变量。同一素材用于浅色和深色界面，装饰图形从辅助技术中隐藏，实际状态和操作由旁边的文本与原生按钮表达。

### 桌面任务详情 · 输出文件

借鉴 [Input 的清除操作](https://ant.design/components/input/)、[Empty 的说明与操作区](https://ant.design/components/empty/)和 [Pagination 的单页隐藏选项](https://ant.design/components/pagination/)，只采用交互方式，继续使用项目内置图标和主题色：

- 搜索按文件名或路径匹配，结果直接展开；没有匹配时可清除筛选，焦点回到搜索框。旧服务若只返回部分文件，搜索框与无匹配提示都明确检索范围。
- 未选任务、任务没有文件、筛选无匹配和读取失败分别说明原因；只有读取失败提供重试，只有筛选无匹配提供清除筛选的空状态按钮。
- 只滚动文件列表，搜索框和分页保留在面板内。当前结果只有一页时只显示数量；多页才显示范围和翻页按钮。更改或清除搜索从第一页开始。

### 桌面协议模板 · 版本卡片

选中一个版本时，用一张[卡片](https://ant.design/components/card/)呈现模板名称、工作流及适用范围。叠层图标表示协议文档，不代表人员或运行状态；中性的[标签](https://ant.design/components/tag/)显示真实版本号，不暗示版本已验证或推荐使用。范围、来源未填时明确提示，不补造信息。

用[分割线](https://ant.design/components/divider/)分开身份、参数说明和操作；按[按钮的主次层级](https://ant.design/components/button/)突出「应用到新任务」，删除靠右且保留确认。导入面向整个模板库，不放入单个版本的操作区。全部图标使用已有的本地 SVG，无新增外部依赖。

更多组件的取舍、官方出处与隔离浏览器验证见[桌面组件选型记录](ANT-DESIGN-COMPONENT-AUDIT.md)。

### 桌面运行概览 · 参数比较

「更多操作 → 比较参数」采用[表格](https://ant.design/components/table/)的并列对照方式，用原生表格显示接口返回的全部差异。滚动时保留两侧任务名；搜索匹配参数路径和任一侧的值，不再截取前 30 项。文字、数字、布尔值与空字符串保持可区分；「未设置」表示接口给出的 `null`，包括该任务没有此参数的情况。没有差异、搜索无匹配、请求失败分别提供说明，只有失败时显示重试。

入口图标直接使用 Ant Design 的 `DiffOutlined`，从 `@ant-design/icons-svg@4.6.0` 随包收录 `diff.svg` 和 MIT 许可证。未引入 React、`antd` 或 CDN 资源。

### 桌面任务详情 · 运行日志

参考 [PatternFly Log viewer](https://www.patternfly.org/extensions/log-viewer/) 的查找和跟随交互，在原有折叠日志面板内实现，不引入组件库运行时。输入关键词在已加载的日志中按字面、不区分大小写查找；Enter / Shift+Enter 前后循环定位，Esc 清除。匹配很多时仍统计全部，只高亮当前一处，以免生成大量标记。

向上滚动、定位匹配或取消「自动跟随」都只暂停滚动，不暂停任务或接收日志。「回到最新」恢复跟随。复制的是当前保留在浏览器的原文，不是搜索结果；下载仍读取服务端已保留的 `run.log`。
