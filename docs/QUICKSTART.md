# 第一次使用 GROMACS Console

本软件在自己的电脑上运行 GROMACS。关闭浏览器不会停止后台计算；关闭计算机或 WSL 会中断任务。

## 先体验完整流程

1. 检查侧栏的“运行环境”。GROMACS 可用后，在“新建任务”里展开“第一次使用”。
2. 点击“运行教学示例”并确认。示例使用 64 个氩原子，运行 1 ps，限定单 CPU 线程，不需要蛋白力场、配体参数化工具或 GPU。
3. 在任务详情查看模拟时间和原生日志更新。刚开始还没有进度数据时会显示“暂无法估算”；日志超过 10 分钟没有更新会提示检查，不能据此断定计算已停止。
4. 完成后打开“分析图谱”查看能量和温度，再点击“导出结果摘要包”。解压 ZIP 后打开 index.html，可离线查看协议、检查记录和已有图表。

尚未配置计算环境时，可以先打开“查看离线示例结果”。该示例附带真实短计算的记录和版本；只用于学习软件操作，不用于得出科研结论。

## 使用自己的结构或轨迹

选择“准备并运行模拟”“分析已有轨迹”或“运行已有 TPR”，然后选择对应流程。上传后检查文件映射和输入就绪提示。引导视图优先显示常用设置；需要完整设置时切换“专业视图”。两种视图使用同一份参数，不会因切换而重置。

蛋白与复合物流程默认协议可能包含 100 ns × 3 副本。务必查看“本次协议”摘要，确认时长、温度、力场、水模型与副本数。教学示例很短，不代表自己的研究也可以使用相同时长。

配体需要确认化学结构、质子化状态与净电荷。不要把默认电荷 0 当作已验证的结果。清理 HETATM、关键结晶水或金属之前需确认其研究意义。

配体自动参数化需要 ACPYPE/AmberTools，结构格式转换使用 Open Babel；运行已准备好的配体拓扑时按所选流程检查输入。二级结构分析使用 GROMACS 内置的 `gmx dssp`，需安装支持该命令的版本，外部 `mkdssp` 不作为这条分析流程的必需项。

“只检查命令（Dry run）”仅检查命令链，不会运行真实模拟，也不能证明结构、力场或采样有效。命令预览始终可以展开检查。

## 重复使用与整理

- 在新任务中填写研究项目、标签和备注；已有任务可在标题下的“编辑实验记录”中修改、置顶。侧栏可按项目筛选，也可搜索标签和备注。
- “协议模板”保存当前参数并保留不可变版本。同名再次保存产生新版本。模板可导出、导入 JSON；文件、机器工具路径和配体电荷确认需要重新选择。
- “复制任务”会复用输入并立即创建排队任务；执行前有确认。仅想修改参数时请先保存模板，再应用到新任务。
- 完成任务可“继续分析”；派生结果显示来源任务入口。

## 结果和故障

结果摘要包默认包含可读取的报告、MDP、XVG、TSV 与 PNG/PDF 图表。限制为 500 个文件、单文件 16 MiB、候选文件合计 64 MiB；跳过项列在摘要中。原始结构、轨迹、checkpoint 和日志在“输出文件”中单独下载。摘要可能包含实验参数和本地环境记录，分享前请检查内容。

“已完成”只表示程序执行结束。质量检查通过也不等于科学结论成立，请结合研究问题判断采样充分性。

任务失败时先看具体原因与恢复建议，修正后使用“重试失败步骤”或可用的“检查点续跑”。不要通过增加 maxwarn 掩盖预处理警告。原生日志可能因较长输出间隔暂时没有新记录。

“帮助与诊断”可预览并下载环境诊断 JSON。该摘要不含结构、轨迹、任务名、用户名、路径和运行日志。下载后由你自行决定是否提供给维护者；软件不会自动上传。
