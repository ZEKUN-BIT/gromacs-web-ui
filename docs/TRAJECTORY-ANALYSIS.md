# 轨迹预处理与 XVG 分析

XVG 保存时间、RMSD、距离等数值，不含可供修复的原子坐标。周期边界处理、居中和拟合必须在生成这些数值之前作用于 XTC/TRR 轨迹。仅调整图表或修改 XVG 无法补做这些操作。

## 0.2.6 的处理流程

生产副本的骨架 RMSD、独立 RMSD 和分析套件的 RMSD 使用：

```text
原始轨迹 → trjconv -pbc nojump
         → trjconv -pbc cluster -center
         → gmx rms -fit rot+trans → RMSD XVG
```

`nojump` 从输入轨迹开头累计处理，再选取分析时间窗口，避免截掉早期历史后重建出不同的周期镜像。`cluster` 将指定溶质组聚拢；聚拢和居中使用同一组，输出保留完整 `System` 以匹配 TPR。蛋白体系默认组为 `Protein`，生产复合物为 `Protein_Lig`。独立分析复杂体系时，请提供 NDX 并把居中组设为实际的蛋白与配体合并组。

`gmx rms` 第一项交互选择是拟合组，第二项是 RMSD 计算组，默认均为 `Backbone`。刚体旋转与平移在分析程序内拟合，不必另存一条拟合 XTC。RMSD 以所选 TPR 的坐标为参考。研究分析另以所选窗口的首个分析帧为参考，并在 MDAnalysis 中完成蛋白拟合；两者的参考定义不同。

| 指标 | 坐标处理与拟合 |
| --- | --- |
| 骨架及独立 RMSD | nojump 后聚拢、居中，`gmx rms -fit rot+trans` |
| 经典配体位置 RMSD | 蛋白与配体聚拢、居中，按蛋白骨架拟合，再计算配体 RMSD |
| 经典 RMSF | 使用聚拢、居中轨迹，`gmx rmsf -fit` |
| PCA | 使用整化轨迹，`gmx covar -fit`；按所选拟合组对齐 |
| Rg、SASA、DSSP | 使用聚拢、居中轨迹；全局刚体拟合不改变这些指标 |
| 接触、最短距离、氢键 | 使用聚拢、居中且未旋转的轨迹，保持坐标与周期盒子方向一致 |
| 研究分析 | 结构指标采用蛋白拟合坐标；接触采用与周期盒子一致的坐标和最小镜像距离 |

独立套件复用 RMSD 已准备的未旋转轨迹；只计算其他结构指标时仍先聚拢、居中。“继续分析”先准备完整体系供其他指标使用，RMSD 另外从原始轨迹保留完整 nojump 历史。能量数据来自 EDR，不需要坐标拟合。

旋转坐标而保留未旋转的周期盒子会改变最小镜像几何。因此不要将用于可视化的拟合轨迹统一作为接触或氢键分析输入。对结构指标，在各自分析程序内完成拟合。

## 文件、时间与已有结果

默认在最后使用后删除派生轨迹，保留原始输入和 XVG。日志及命令预览仍列出预处理与拟合；输出目录没有拟合 XTC 不表示没有拟合。需要可视化轨迹时，在“轨迹后处理”中选择旋转平移拟合并勾选“保留拟合轨迹”。

“继续分析”以 ns 接收范围。`trjconv` 的截取参数换算为 ps，`gmx rms -tu ns` 的范围仍使用 ns。例如 20–80 ns：nojump 读取开头到 80000 ps，聚拢截取 20000–80000 ps，RMSD 输出 20–80 ns。分析前磁盘预算考虑输入副本、同时存在的派生轨迹、输出与余量；估算不预分配文件，也不是实际峰值保证。

升级不会重写历史任务的命令或已生成 XVG。对旧结果使用“继续分析”新建分析任务，才能应用新流程。输入 TPR、轨迹和 NDX 必须具有一致的原子顺序；PBC 修复与拟合不替代结构、组选择和模拟采样的科学判断。

## 验证

在真实 GROMACS 2025.4 中处理合成的双链、六原子、121 帧轨迹，包含周期跨界和整体旋转、平移。独立 RMSD、套件及继续分析的 20–80 ns 窗口均输出 61 行，刚体 RMSD 残余不超过 `5 × 10⁻⁷ nm`；生产分析的 121 行残余不超过 `6 × 10⁻⁷ nm`。Rg 为 `0.567891 nm`，与解析值 `0.56789083458 nm` 一致，派生轨迹均按流程清理。

该验证运行预处理和分析，没有执行 MD；它验证坐标与时间处理行为，不证明真实体系的平衡或收敛。
